# Proyecto MERN 
## Descripción

Este proyecto es la estructura inicial de una aplicación web utilizando el stack MERN:

- MongoDB
- Express
- React
- Node.js

## Estructura del proyecto

Proyecto.Mern/

backend/
Servidor Node.js con Express

frontend/
Aplicación React

## Instalación

### Backend

cd backend
npm install
node index.js

### Frontend

cd frontend
npm install
npm start
